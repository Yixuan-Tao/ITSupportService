# 软件安装与授权申请流程

## 默认可自助安装的软件
- Chrome
- Zoom
- 企业微信
- Office 套件
- VS Code
- 7-Zip

## 需要审批的软件
- Adobe 系列
- JetBrains 商业授权
- 数据库客户端
- 设计类软件
- 抓包/调试工具
- 远程控制工具

## 标准申请流程
1. 在支持门户选择“软件安装/授权申请”
2. 填写软件名称、版本、用途、紧急程度
3. 如为收费软件，需填写成本中心
4. 审批通过后由 IT 安装或下发授权

## 安装失败排查
- 是否具备本地管理员权限
- 是否被杀毒或安全策略阻止
- 是否与现有版本冲突
- 是否系统版本不兼容

## 工单需提供的信息
- 软件名称
- 版本号
- 设备资产编号
- 操作系统版本
- 错误截图
