# Jira 字段映射规则

## 基本字段
- project.key = IT
- issuetype.name = Task

## 业务映射
- summary = 工单标题
- description = 结构化问题描述
- priority = 优先级
- labels = 分类标签
- customfield_device_type = 设备类型
- customfield_os = 操作系统
- customfield_urgency = 紧急程度

## description 结构建议
1. 用户信息
2. 问题现象
3. 影响范围
4. 已尝试步骤
5. 设备与系统信息
6. 附件说明
